# happy-birthday-tonor 🎀

An interactive My Melody birthday website made with love for ต้นอ้อ ♡

Three pages — HOME, BIRTHDAY MESSAGE, MAKE A WISH — with pastel pink glassmorphism, floating hearts, stars, confetti, a CSS birthday cake, background music, and a hidden secret message.

## Features

- 🎂 Interactive 3-page flow: Home → Birthday Message → Make a Wish
- 💗 Animated CSS cake with candle, flame, smoke, and glow
- 🎆 Particles, stars, hearts, and confetti celebration
- 🎵 Background music (`Flower Day`) that starts on "OPEN THE GIFT"
- 💌 A hidden secret message with a pixel reward
- 📱 Responsive for mobile, `prefers-reduced-motion` supported

## How to run

Just open `index.html` in any modern browser. No build step needed.

Pure HTML5 + CSS3 + Vanilla JS. No frameworks.
